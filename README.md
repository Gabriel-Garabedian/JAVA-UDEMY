# JAVA-UDEMY

Repositório de estudos onde registro meu progresso aprendendo Java, com exercícios e anotações de um curso na Udemy.

## Sobre

Cada pasta corresponde a um módulo do curso, na ordem em que foi estudado. Os arquivos `.java` são exercícios resolvidos e pequenos programas de prática, muitos com comentários explicando a lógica ou o motivo de um erro.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `1- extrutura sequencial` | Exercícios de estrutura sequencial (entrada, cálculo, saída) |
| `2- extrutura condicional` | Exercícios com `if` / `else if` / `else` |
| `3- sintaxe opicional` | Escopo de inicialização, expressão condicional ternária, operadores de atribuição cumulativa (`+=`, `-=`...), `switch case` |
| `4- extruturas repetitivas` | Laços de repetição, separados em `For`, `While` e `DoWhile` |
| `5- Topicos Basicos Sobre Java` | Funções para `String`, sintaxe de funções, restrições para nomes de variáveis |
| `6- POO` | Programação Orientada a Objetos *(em andamento)* |

## Tecnologias

- Java
- `Scanner` para leitura de entrada do usuário

## Como executar um exercício

```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```
